项目概述

本系统针对"图文混合的考古/历史问答"赛题，实现了端到端 Multimodal RAG Agent， 支持 6 种题型：判断 QA/VQA、简答 QA/VQA、选择 QA/VQA。 核心创新是按题型路由的混合检索与错题驱动的 prompt 格式化优化， 从 76% baseline 突破到 80%（40/50）。

关键发现

⚠️ 答案泄露陷阱

把 mock 的 (question, expected_answer) 加进 BM25 索引会虚高 +12.5pp —— BM25 字符匹配让"问：图中文物名称"完全命中"问：图中文物名称?答：齐侯盂"，相当于答案泄露。 已废弃此路径，仅保留干净自举 corpus。

💡 不同检索方法各题型表现差异极大

120 题 stratified mock 实测：判断题 BM25 +10pp（专名命中）但简答 QA 不动； 简答 QA HyDE +20pp 但判断题反而 -5pp。 → 启发"按题型路由"设计。

📐 Prompt 格式化对评测严格匹配是关键

错题分析显示 ≥10/13 简答 QA 错题是格式问题（缺"省"/"帝"/"。"/"顿号"等）。 重写 SYS_SHORT 按题问类型强制格式后，简答 VQA 71% → 86%（救回 6164 链子→链条、6295 光→宝）。

🎚️ Prompt 规则触发条件要显式排除反例

SYS_JUDGE_SOFT 加 TF 验证规则 v1 太宽（"题面长 + 含答案"）→ 把分析论述题也翻成正确， 赔 5 救 3。v2 收紧到"精确含'该问题的答案是'字串"，论述题不触发，最终 +2 题达成 80%。
